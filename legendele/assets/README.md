# Sprite-uri (pixel art)

Jocul desenează singur toate elementele grafice din cod. Ca să înlocuiești un desen cu pixel art,
pune aici un fișier PNG (cu transparență) cu numele de mai jos. Jocul îl folosește automat.

| Fișier | Ce este | Mărimea desenului din cod |
|---|---|---|
| `army_voievodat.png`, `army_zmei.png`, `army_iele.png`, `army_strigoi.png` | Steagul armatei pe hartă | 30×36 px |
| `castle.png` | Capitală (aceeași imagine pentru toate facțiunile) | 39×21 px |
| `heart.png` | Inima Munților | 27×27 px |

Sfat: desenează la o rezoluție mică (de ex. 10×12 pixeli) și mărește de 3× fără netezire,
ca să se potrivească cu restul hărții.
